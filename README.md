# To Do List (JavaScript)

A simple to-do list web app made with **HTML, CSS, and Vanilla JavaScript**.

## Features
- Add tasks
- Edit tasks
- Remove tasks
- Persists tasks using **localStorage**

## How to run
1. Open `index.html` in your browser.

## Project structure
- `index.html` – UI
- `style.css` – styling
- `script.js` – add/edit/remove + localStorage logic

## Demo
Just open `index.html` to view the app locally.
